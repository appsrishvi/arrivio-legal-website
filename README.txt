HOW TO PUBLISH
1. Upload ALL FIVE files to the same web hosting directory (do not omit the PNG or CSS).
2. Open index.html to view the legal centre.
3. Use the absolute public URLs for privacy-policy.html and terms-of-use.html in your app
   and for the Privacy Policy field in your app-store listing.
4. The pages are static: no analytics, cookies, account system or backend required.
   Hosting providers may independently retain standard web server logs.
